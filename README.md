# 🎓 EduPro — Predictive Analytics Platform

An end-to-end Machine Learning application designed to forecast course enrollments and revenue for an online learning platform.

EduPro combines data analysis, feature engineering, machine learning, and an interactive Streamlit dashboard to generate data-driven insights for educational platforms.

## 🚀 Project Overview

EduPro focuses on three prediction tasks:

1. **Course Enrollment Prediction** — Forecast future enrollments for individual courses.
2. **Course Revenue Prediction** — Estimate future revenue generated by individual courses.
3. **Category Revenue Prediction** — Forecast revenue across course categories.

## ✨ Key Features

- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- Feature engineering and historical lag features
- Time-based training and testing split
- Expanding-window cross-validation
- Hyperparameter tuning using GridSearchCV
- Multiple regression algorithms
- Model evaluation using MAE, RMSE and R²
- Interactive Streamlit dashboard
- Historical performance visualizations
- Future enrollment and revenue predictions

## 🧠 Machine Learning Models

Three models were selected for the final prediction tasks:

| Prediction Task | Selected Model |
|---|---|
| Course Enrollment | Ridge Regression |
| Course Revenue | Random Forest Regressor |
| Category Revenue | Gradient Boosting Regressor |

Other algorithms explored included Extra Trees, Random Forest, Gradient Boosting, Ridge Regression and XGBoost.

## 📊 Model Evaluation

The following results were obtained using the original held-out October–December 2025 test set.

| Prediction Task | Model | MAE | RMSE | R² |
|---|---|---:|---:|---:|
| Enrollment | Ridge | 2.81 | 3.69 | -0.016 |
| Course Revenue | Random Forest | 247.82 | 619.06 | 0.920 |
| Category Revenue | Gradient Boosting | 1016.56 | 1529.15 | 0.936 |

**Note:** The enrollment model has a slightly negative R² and performs only marginally better than the global-mean baseline. This indicates that enrollment forecasting remains a limitation and an opportunity for further improvement.

The final saved models were subsequently refitted using all available historical data through December 2025. The evaluation results above refer to the earlier held-out test evaluation, not an independent evaluation of those refitted models.

## 🔍 Machine Learning Workflow

1. Dataset collection and loading.
2. Data validation and cleaning.
3. Exploratory Data Analysis.
4. Transaction, course and teacher data integration.
5. Monthly aggregation at course and category levels.
6. Feature engineering using lag and rolling statistics.
7. Chronological training and testing split.
8. Expanding-window cross-validation.
9. Hyperparameter optimization.
10. Model evaluation and selection.
11. Final model training and serialization.
12. Streamlit application development.

## 💻 Installation and Execution

### 1. Clone the repository

```bash
git clone https://github.com/manmeetmanchanda10016/EduPro-Predictive-Analytics.git
```

### 2. Navigate to the project directory

```bash
cd EduPro-Predictive-Analytics
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the environment

Windows:

```powershell
.\venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.
